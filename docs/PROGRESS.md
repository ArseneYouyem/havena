- 2026-09-29 — Phase 8 : module **Finances**, pattern dialog simple (comme Abonnements) avec deux liens optionnels (client et/ou prestataire). - 2026-09-29 — Phase 9 : module **Rapports mensuels** avec génération PDF réelle. `RapportPdfGenerator` écrit à la main (pas délégué, pour maîtriser l'API `pdf`/`printing` fraîchement vérifiée via la doc à jour) — le PDF est sauvegardé dans le stockage applicatif puis ouvert en aperçu natif via `printing`. Bug détecté et corrigé grâce au test d'intégration (pas juste par l'analyse statique) : la police PDF de base (Helvetica) ne supporte pas certains caractères Unicode (tiret cadratin « — », coche « ✓ », croix « ✗ ») qui ne se seraient pas affichés dans le document généré — remplacés par un tiret simple et des libellés texte « [Oui] »/« [Non] ». Les caractères accentués français (é, à...) restent inchangés, ils sont bien supportés par la police de base.
